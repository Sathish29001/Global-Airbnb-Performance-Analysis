# Global-Airbnb-Performance-Analysis
The report tracks global listing expansion, which peaked in 2015 before facing tighter local regulations, and resolved this bottleneck by turning profitable in late 2016.

Airbnb Performance Dashboard: Interactive Power BI analytics tracking 279,712 listings, 1.8M hosts, and 5.3M+ reviews across 10 global cities. 

Growth & Regulation Insights: Identifies listing bottlenecks from tightening local regulations (2016–2017) alongside financial shifts toward profitability.  

Geographic Market Dynamics: Maps show heavy concentration in key markets like Paris, NYC, and Sydney, highlighting competitive pricing relative to traditional hotels.  

Service Quality Evaluation: Pinpoints core rating gaps in cleanliness and value for money while highlighting top-performing hubs like Mexico City and Rio.  

Host Trust & Engagement: Evaluates review seasonality patterns and host credibility signals, showing over 66% verified host identities.
